# SJA Fitness

An online fitness platform landing page — currently in pre-launch mode, collecting waitlist sign-ups before going live. Part of the [SJA Ecosystem](https://sja-thedude.github.io/sja-ecosystem).

## Features

- **Hero** — "Train Anywhere. Win Everywhere." with waitlist CTA
- **Services** — AI workout plans, nutrition guides, 1-on-1 coaching, community challenges, progress tracking, and social features
- **Pricing** — Free, Pro ($9.99/mo), and Elite ($19.99/mo) tiers
- **Shop Teaser** — Preview of the upcoming SJA Wear fitness clothing line
- **Waitlist** — Email capture form for early access

## Tech Stack

- [Next.js](https://nextjs.org/) 16 (App Router)
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/) 5
- [Tailwind CSS](https://tailwindcss.com/) 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run start` | Start production server  |
| `npm run lint`  | Run ESLint               |
